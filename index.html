Como hospedar este Roadmap no seu GitHub Pages gratuitamente

Transforme este arquivo em um site público no seu domínio seu-usuario.github.io em menos de 3 minutos.

1

Salve o arquivo index.html

Clique no botão "Exportar Backup" nesta página ou salve o código como index.html.

2

Crie um Repositório no GitHub

Acesse github.com/new, crie um repositório público chamado roadmap-dados e faça upload do arquivo index.html na raiz.

3

Ative o GitHub Pages

Vá em Settings > Pages, selecione a branch main e clique em Save. Pronto!
